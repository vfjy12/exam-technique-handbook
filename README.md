# 考公技巧宝典 0.1.0

独立 Obsidian 插件，插件 ID exam-technique-handbook，兼容移动端 API，无桌面文件系统依赖。

支持老师筛选、技巧节点父子 ID、完整讲义内容及 MD/PDF 来源链接、关联原题的分析模板；分析分为题干、问题、A/B/C/D 选项、应用和关联技巧。老师原讲解、个人应用、AI 建议分别标记。题目只保存路径链接，不复制整题。

内容保存在 技巧宝典/技巧、讲义、题目分析，独立 MD 是主数据；后续修改用“打开原 Markdown 编辑”。来源、父节点或原题路径需填写库内路径/ID；现阶段不是可视化选文件器。不会自动提取 PDF/OCR 或老师观点。

安装：将目录 exam-technique-handbook 放到库配置目录的 plugins 下，重启 Obsidian，在第三方插件启用。无需覆盖其他插件或配置。iCloud 传输后需在各设备启用；网页版不能解压插件安装到隐藏目录。

验证：语法及文档生成/关联逻辑模拟检查；Obsidian/iPad 实机未验证。此版本未完成整套设计中的原题内逐字高亮、老师对比视图、漫游内嵌分析或多维表格接入，不代表完整规划交付。先在探索库测试。
