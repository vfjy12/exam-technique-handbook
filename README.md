# 考公技巧宝典 0.5.0

按模块维护分类树，在分类下导入或编辑不同老师的方法体系。题干分析、问题分析、选项分析和关键词通过同一老师的节点分别维护；可给节点设置漫游位置与用途颜色。Markdown 导入会将与模块同名的顶层标题映射到模块，不重复生成技巧根节点。

蒙题经验保存在 `技巧宝典/个人蒙题经验/<模块>/<题型路径>.md`，同一道题再次记录会更新原块。原题 YAML 中已有的蒙题历史仍按漫游插件的逻辑保留。

这是用于 iPad/Windows 实测的测试版。建议先备份 Obsidian 库。BRAT 仓库：`vfjy12/exam-technique-handbook`。Release 提供 `main.js`、`manifest.json`、`styles.css`。
