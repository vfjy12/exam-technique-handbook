# 考公技巧宝典 0.7.0

打开插件直接进入预置的考试模块与题型树工作区；模块切换栏始终显示基础模块，会为已有空分类树补齐基础模块和常见题型，同时保留用户自定义分类。工作区自上而下显示题型、老师体系、分析分区和分析条目。分析区可快速新增并逐行维护。关键词支持“如果…那么…”触发规则，漫游会对题干和选项执行忽略空格标点的模糊匹配。可在方法导图、题干分析、问题分析、选项分析、关键词和个人蒙题经验视图间切换。Markdown 导入会将与模块同名的顶层标题映射到模块，不重复生成技巧根节点。

蒙题经验保存在 `技巧宝典/个人蒙题经验/<模块>/<题型路径>.md`，同一道题再次记录会更新原块。原题 YAML 中已有的蒙题历史仍按漫游插件的逻辑保留。

漫游中确认匹配方法后，会在题目 YAML 的 `technique_method_matches` 留下方法稳定 ID、老师体系、分析位置、典型类别和人工复核说明；同一方法与分析位置再次确认会更新原记录。插件另保存可读的个人应用分析笔记，便于漫游按老师体系展示。

这是用于 iPad/Windows 实测的版本。建议先备份 Obsidian 库。BRAT 仓库：`vfjy12/exam-technique-handbook`。Release 提供 `main.js`、`manifest.json`、`styles.css`。
